# Fonts Directory

This directory should contain the Poppins font files:

- Poppins-Regular.ttf
- Poppins-Medium.ttf
- Poppins-SemiBold.ttf
- Poppins-Bold.ttf

## Download Fonts

You can download Poppins fonts from:
- Google Fonts: https://fonts.google.com/specimen/Poppins
- Font Squirrel: https://www.fontsquirrel.com/fonts/poppins

## Installation

1. Download the font files
2. Place them in this directory
3. The app will automatically load them on startup

## Fallback

If fonts are not available, the app will use system default fonts (Inter, San Francisco, Roboto).
